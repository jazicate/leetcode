# LeetCode Prep
This repo is basically my working space for interview prep.  
It’s a mix of templates, notes, and solved problems — organized in a way that makes it easy to review patterns and reuse ideas.

---
## LeetCode Resources
Most of this is based on LeetCode’s interview crash course:  
[https://leetcode.com/explore/interview/card/cheatsheets/720/resources/](https://leetcode.com/explore/interview/card/cheatsheets/720/resources/)

### Code Templates
Python templates for common patterns (two pointers, sliding window, BFS/DFS, DP, etc).
The goal here is not to memorize code line-by-line, but to:
- recognize patterns faster
- have a starting point when stuck
- avoid rethinking the same logic every time

---
### Other Stuff
- `Cheatsheet.md` → condensed notes from the crash course
- `Stages of an Interview.md` → general interview flow / expectations
- `Images/` → diagrams that help visualize some patterns

---
## LeetCode 150
I’m working through the LeetCode 150 list and grouping problems by pattern/topic instead of just difficulty.

Each folder = a category like:
- Array / String
- Hashmap
- Two Pointers
- etc.

For each problem, I try to include:
- solution code
- what pattern it falls under
- time/space complexity
- short notes if something was tricky
